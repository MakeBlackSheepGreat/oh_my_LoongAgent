**目标**：将项目中心工作台打磨为更接近成熟 Coding Agent 的项目、任务、对话和执行节奏，并加入安全、可切换、可诊断的供应商档案管理能力。

## 设计边界

- 工作台继续以受信任本地项目、连续会话和审批后的任务运行作为主线；论文搜索只作为已注册 Skill。
- 交互借鉴 Codex 的项目和任务可见性，以及 Claude Code 的对话内阶段反馈与受控工具意识；不复制品牌、视觉资产、文案或外部源代码。
- 供应商档案采用 OpenAI 兼容协议。档案仅保存显示名、端点、模型列表、默认模型、环境变量密钥引用、启用状态和连通性结果。
- API Key 永不写入 SQLite、浏览器存储、事件、工件或响应；浏览器只能获知“已配置”状态和环境变量名称。
- 核心 `harness/` 保持通用。档案持久化、激活偏好和页面交互属于 `workbench/` 与 `web/`。

## 验收

1. 用户可管理多个供应商档案，通过一个显式动作切换当前档案并应用到当前项目和会话。
2. 用户可看到端点、默认模型、模型候选、密钥环境变量名、启用状态和最新连通性结果；任何页面与 API 均不返回密钥值。
3. 供应商测试使用最小的兼容接口请求，记录结果、延迟、时间与标准错误码，不记录请求凭据或响应体。
4. 对话主面保留输入、可见答复、任务草案、阶段反馈和运行状态；计划、工件、来源、预算与审批继续由检查器承载。
5. 后端测试和前端构建通过；浏览器在桌面及窄屏完整检查供应商管理、切换和聊天入口。
