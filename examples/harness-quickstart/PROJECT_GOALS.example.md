# 项目目标（示例模板）

**版本**：v0.1  
**更新时间**：2026-08-01  
**项目名称**：通用 Agent Harness 示例项目

本文件只定义项目目标、研究问题、成功指标和最终成果。执行计划见 `SPEC.md`，硬边界见 `RULES.md`，主观风格见 `SOUL.md`，候选创新见 `IDEA.md`。

## 总目标

构建并评测一个以轻量级模型为核心、可选择低成本云端模型的通用 Agent Harness。系统以任务契约、受限工具、版本化工件、验证器、恢复、审计、Skill 和记忆为底座，在有限资源预算内完成真实工具任务，并保持执行可验证、状态可回放、错误可恢复、风险可治理。

## 架构边界

- 通用核心只处理任务、动作、工件、状态、预算、权限、验证、策略和回放，不依赖特定领域。
- 业务 Skill 通过标准接口注册，独立于核心运行时。
- 强教师仅用于离线生成和抽检冻结参考包。用户运行时只使用配置的学生模型、受控工具与人工审批。

## 产品能力目标

### G1：可执行

系统能够理解任务、生成类型化动作、调用受限工具并提交满足验收条件的工件。

### G2：可验证

每个任务拥有明确成功判据；工具结果、状态差分、引用、测试和权限均可由独立验证器检查。

### G3：可回放

任务输入、模型配置、动作契约、工具观察、工件版本、验证结果和终态可以重建一次执行。

### G4：可恢复

失败能够归类到任务理解、状态读取、路由、工具、参数、验证、权限或运行时，并导向定向修复、升级、停止或人工审批。

### G5：预算可控

模型调用、上下文、候选、工具等待、并发、强模型升级和总成本拥有显式预算与停止条件。

### G6：经验可积累

经验证的成功与失败可以转化为可检索技能、测试夹具、错误映射和可选轻量训练数据，并在保留集上检验复用价值。

## 成功指标

| 维度 | 指标 |
| --- | --- |
| 任务质量 | 成功率、约束满足率、证据正确率、Schema 合法率 |
| 工具可靠性 | 工具选择、参数正确率、执行成功率、回滚成功率 |
| 协作效率 | 端到端时延、token、资源峰值、调用次数、无效通信、重试率 |
| 恢复能力 | 失败定位率、恢复成功率、错误复现率、过期状态引用率 |
| 治理 | 越权拦截率、泄露检测率、人工接管率、审计完整率 |
| 可复现性 | 重复运行方差、环境记录完整度、工件哈希与回放成功率 |

## 最终成果

1. 一套可在单机环境运行的轻量级 Agent 运行时。
2. 一个包含模拟工具、确定性验证器和风险分层的中文日常任务集。
3. 单 Agent、固定多 Agent、动态路由和教师反馈系统的完整消融结果。
4. 可复用的动作契约、工件协议、审计事件、错误码和失败分类规范。
5. 可公开的代码、匿名化任务数据、实验报告、数据卡、模型卡和复现指南。
