# 基础模型到 Agent 迁移分析（示例模板）

本文件保存基础模型论文与 Agent 系统之间的迁移分析矩阵。每条记录标注论文的核心机制、Agent 可迁移性评估、以及与本项目候选创新的对应关系。

## 使用方式

在你的项目中，使用此文件记录以下内容：

1. 每篇基础模型论文中的可迁移机制。
2. 该机制在 Agent 系统中的适用场景与预期收益。
3. 与本项目 `IDEA.md` 中候选创新的对应关系。
4. 迁移优先级评估（高/中/低）与实施难度。

## 模板格式

```md
### 论文标题

- **arXiv ID**：xxxx.xxxxx
- **厂商**：厂商名称
- **核心机制**：[简要描述]
- **Agent 迁移评估**：[可迁移性分析]
- **对应 IDEA**：[IDEA.md 中的条目编号]
- **优先级**：高 | 中 | 低
- **备注**：[额外说明]
```
